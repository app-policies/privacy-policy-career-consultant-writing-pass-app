# キャリコン論述Pass プライバシーポリシー

最終更新日　2026年11月25日

対象バージョン　1.0.0

キャリコン論述Pass（以下「本アプリ」）は、キャリアコンサルタント試験の論述を、面談事例と短い答案で練習するための非公式の学習アプリです。

## 取得する情報

本アプリと、アプリの提供に利用する外部サービスでは、次の情報を取り扱います。

- 端末に保存する学習データ。入力した答案、自己確認の状況、お気に入りに登録した事例など。
- アプリの利用状況。起動、学習の開始・完了、回答操作、学習完了時の回答数など。
- 広告の配信、効果測定、不正防止に必要な情報。端末やアプリの識別子、IPアドレスから推定されるおおよその地域、広告の表示や操作に関する情報など。
- アプリ内課金の購入状態を確認・復元するための識別子や購入情報。
- 外部サービスのSDKや、利用者の設定に応じたOS標準の診断機能が取り扱う動作状況やクラッシュに関する情報。
- 利用者が問い合わせメールを送信した場合の送信元メールアドレス、メール本文、利用者が添付した情報。

アプリ独自の利用者アカウントは設けていません。連絡先へのアクセスや、端末の位置情報サービスによる正確な位置情報の取得を求める機能はありません。

## 利用目的

- 答案、自己確認の状況、お気に入りを保存し、学習や復習に利用できるようにするため。
- アプリの利用状況を把握し、学習機能や使い勝手を改善するため。
- 広告の表示、効果測定、不正利用の防止のため。
- プレミアムの購入状態を確認し、購入済みの機能を復元するため。
- 不具合の調査、動作の改善、問い合わせへの対応のため。

## 学習データの保存

入力した答案、自己確認の状況、お気に入りは端末内に保存します。本アプリの学習機能から、これらの学習データを運営者のサーバーや外部AIサービスに送信することはありません。本アプリによるクラウド同期機能はありません。

アプリ内の「設定」から「学習データをリセット」を選ぶと、この端末に保存された答案、自己確認の状況、お気に入りを消去できます。この操作は、購入履歴や外部サービスで取り扱われた情報の削除には適用されません。アプリの削除や端末の変更により、学習データが失われる場合があります。

## Firebase Analytics の利用

アプリの利用状況を把握し、機能や品質を改善するため、Google が提供する Firebase Analytics を利用します。本アプリは、起動、学習の開始、回答操作、学習の完了を集計します。学習完了時の回答数やアプリのバージョン、OSの種類などを送信します。SDKが自動で収集する基本的な利用状況や、アプリのインストールを区別するための識別子なども取り扱われる場合があります。

アプリ独自の分析イベントには、入力した答案の本文、問題や解説の本文、お気に入りの登録内容、問い合わせ内容を含めません。

- [Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)
- [Firebase Analytics が自動で収集する情報](https://firebase.google.com/docs/analytics/reports)

## 広告について

Google AdMob を使い、バナー広告と全画面広告を表示します。アプリからは非パーソナライズド広告をリクエストします。プレミアムの購入状態が確認されると、アプリ内の広告表示が非表示になります。

Google Mobile Ads SDK は、広告配信、効果測定、不正防止、サービスの改善のため、端末やアプリの識別子、IPアドレスから推定されるおおよその地域、広告の表示や操作に関する情報、動作やクラッシュに関する診断情報を取り扱う場合があります。

- [Google AdMob の非パーソナライズド広告について](https://support.google.com/admob/answer/7676680?hl=ja)
- [Google Mobile Ads SDK のデータの取り扱い](https://developers.google.com/admob/ios/privacy/data-disclosure)

## アプリ内課金について

買い切りのプレミアムを購入すると、すべての事例で練習でき、広告が非表示になります。

決済は App Store を通じて Apple が処理します。購入状態の確認や復元には RevenueCat を利用します。RevenueCat は購入状態の管理に必要な、アプリ内の利用者を区別するための自動生成の識別子や、App Store の購入情報を取り扱います。運営者がカード番号や Apple アカウントのパスワードを受け取ることはありません。

## 外部サービス

- Firebase Analytics は利用状況の分析に利用します。[Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)
- Google AdMob は広告の配信と効果測定に利用します。[Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- RevenueCat は購入状態の確認と復元に利用します。[RevenueCat プライバシーポリシー](https://www.revenuecat.com/privacy)
- Apple は App Store での決済に関わり、利用者の設定に応じてOS標準の診断情報を取り扱うことがあります。[Apple プライバシーポリシー](https://www.apple.com/jp/legal/privacy/)

各サービスにおける情報の取り扱いは、サービス提供者の案内をご確認ください。

## 第三者提供

外部サービスとは、上記の目的に必要な情報がやり取りされます。運営者が個人情報を第三者に提供する場合は、法令に従い、本人の同意が必要なときは事前に同意を得ます。

## 本アプリで提供しない機能

本アプリは、オリジナルの面談事例と解答例を用いて、試験に向けた答案の作成と自己確認を支援します。AIによる添削、自動採点、試験の公式採点、個別のキャリア相談、合格の保証は提供しません。
